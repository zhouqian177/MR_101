## 1. MR 分析类型总览

### 1.1 按数据类型分

| 类型 | 数据需求 | 代表方法 | 本仓库模块 |
|---|---|---|---|
| 两样本 MR（Two-sample MR） | 暴露/结局 GWAS 汇总数据 | IVW、Egger、加权中位数 | 02/03 主流程 |
| 单样本 MR（One-sample MR） | 个体水平基因型+表型 | 2SLS 两阶段最小二乘 | 扩展 1（10_one_sample_mr.R） |
| 多变量 MR（MVMR） | 多暴露 + 结局汇总数据 | MV-IVW、MV-Egger | 扩展 2（11_mvmr.R） |
| 两步中介 MR | 暴露、中介、结局三套数据 | 乘积法分解间接效应 | 扩展 3（12_mediation_mr.R） |

### 1.2 按多效性处理策略分

| 方法 | 策略 | 适用场景 | 本仓库模块 |
|---|---|---|---|
| IVW | 假设所有 SNP 有效 | 主分析（默认） | 02 主流程 |
| MR-Egger | 允许定向多效性（截距项） | 多效性存在时 | 02 主流程 |
| 加权中位数 | ≥50% 权重来自有效 SNP | 稳健性补充 | 02 主流程 |
| 加权/简单众数 | 最大 SNP 簇有效 | 稳健性补充 | 02 主流程 |
| MR-PRESSO | 检测并校正离群 SNP | 水平多效性检验 | 03 敏感性 |
| 径向 MR（RadialMR） | Q 统计量离群检验 | 离群 SNP 可视化 | 扩展 4（13_radial_mr.R） |
| MRMix | 高斯混合模型区分有效/无效 IV | 大量无效 IV 存在 | 扩展 5（14_mrmix.R） |

### 1.3 按研究问题分

| 类型 | 问题 | 关键工具 |
|---|---|---|
| 因果推断 | 暴露是否因果影响结局 | 上述全部 |
| 中介分析 | 通过何种途径影响 | 两步 MR、乘积法 |
| 共定位 | 是否共享因果变异（排除 LD 假关联） | coloc（扩展 6） |
| 药物靶点 MR | 蛋白/基因表达→疾病的因果效应 | cis-MR、pQTL MR |
| 非线性 MR | 效应是否随暴露水平变化 | 分位数 MR、分段 MR |
| 反向因果检验 | 因果方向是否正确 | Steiger（02 主流程） |
| MR 扫描 | 全表型组扫描（PheWAS-MR） | 批量两样本 MR |

## 2. MR 核心假设与检验映射

| 假设 | 内容 | 检验方法 | 失败后果 |
|---|---|---|---|
| 相关性 | 工具与暴露强相关 | F 统计量（>10） | 弱工具偏倚 |
| 独立性 | 工具与混杂无关 | 平衡性检验（如 MR-Egger 截距≈0） | 定向多效性 |
| 排他性 | 工具仅经暴露影响结局 | PRESSO、径向 Q、leave-one-out | 水平多效性 |

## 3. 各扩展模块方法学要点

### 3.1 单样本 MR（One-sample MR）
- 个体水平数据，工具 SNP → 暴露 → 结局在同一人群
- **2SLS**：第一阶段暴露对工具回归得拟合值，第二阶段结局对拟合值回归
- 优点：可用完整协变量、检测非线性；缺点：弱工具偏倚更敏感、需个体数据
- 关键检验：第一阶段 F 统计量（F<10 存在弱工具）

### 3.2 多变量 MR（MVMR）
- 同时纳入多个暴露，估计**校正其他暴露后**的因果效应
- 解决暴露间相关性导致的混淆（如 LDL/HDL 均与 CHD 相关）
- MV-IVW：广义逆方差加权；MV-Egger：校正多效性
- 注意：每个暴露都需要足够的强工具

### 3.3 两步中介 MR
- 分解：总效应 = 直接效应 + 间接效应
- 第一步 X→M（a），第二步 M→Y（b），间接效应 = a×b
- 中介比例 = 间接效应 / 总效应；SE 用 delta 法或 bootstrap
- 要求：中介的方向假设明确，两步都需满足 MR 假设

### 3.4 径向 MR（Radial MR）
- 将每个 SNP 表示为径向图上的点，其到回归线的距离即 Q 统计量贡献
- 超过卡方阈值的点 = 离群 SNP（潜在多效性）
- 剔除离群后重估更稳健（本仓库实例: 剔除 rs2736428 后 P 从 0.048 降至 6e-5）

### 3.5 MRMix
- 假设 SNP 分两类：有效 IV（无多效性）与无效 IV（有多效性）
- 高斯混合模型估计因果效应 θ、有效比例 π0、多效性方差 σ²
- π0 低时（多效性普遍）仍可一致估计，优于 IVW/Egger

### 3.6 共定位（Colocalization）
- 解决：MR 显著关联到底是共享因果变异，还是两个 LD 内不同变异（假关联）
- coloc.abf：贝叶斯计算五种假设后验概率 H0~H4，**PP.H4 = 共享因果变异**
- 判读：PP.H4 > 0.8 支持共定位；PP.H3 高提示 LD 假关联
- 应用：eQTL/pQTL 数据 + 疾病 GWAS，验证 MR 结果

## 4. 完整 MR 分析工作流（Checklist）

1. 数据准备：暴露/结局 GWAS（样本量、人群、性状类型）
2. 工具变量提取：P < 5e-8，LD clumping（r²<0.001, 10Mb），F>10
3. Harmonise：统一效应等位基因，剔除回文 SNP
4. 主分析：五种方法 + OR/CI
5. 敏感性分析：Q 异质性、Egger 截距、PRESSO、leave-one-out、Steiger、径向
6. 稳健性交叉：MRMix 等替代方法
7. 共定位验证（可选但推荐）
8. 报告：STROBE-MR 清单 + 结果表/图

## 5. STROBE-MR 报告规范（强化版清单）

STROBE-MR（Skrivankova et al., 2021）为 MR 研究报告提供 20+ 项清单，
核心条目：

| 条目 | 要求 |
|---|---|
| 研究设计 | 明确单/两样本 MR、数据来源（暴露/结局 GWAS 引用） |
| 背景与理由 | 为什么用 MR、三大假设的生物学理由 |
| 数据描述 | 人群、样本量、基因分型平台、GWAS 版本 |
| 工具变量选择 | P 阈值、clumping 参数、F 统计量 |
| Harmonise | 等位基因对齐方式、回文 SNP 处理 |
| 统计分析 | 主要方法（预先声明）、敏感性分析计划 |
| 多效性处理 | Egger 截距、PRESSO、径向等 |
| 异质性报告 | Cochran Q、I² |
| 反向因果 | Steiger 检验 |
| 结果呈现 | 森林图/散点图、OR(95%CI)、每方法单独列示 |
| 局限讨论 | 弱工具、多效性、人群差异、样本重叠 |
| 可复现性 | 脚本、数据版本、随机种子 |
