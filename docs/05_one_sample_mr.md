# 单样本 MR 报告（05_one_sample_mr）

> 对应模块：扩展 1 —— 单样本孟德尔随机化（One-sample MR）。
> 脚本：`scripts/10_one_sample_mr.R`；产物：`02.analysis/one_sample/`、`04.figures/one_sample_*.png`

## 1. 方法学

单样本 MR 使用**个体水平数据**（基因型 + 表型在同一人群），通过
**两阶段最小二乘（2SLS）** 估计因果效应：

1. 第一阶段：暴露 X 对工具变量基因型 G 回归 → 拟合值 X̂
2. 第二阶段：结局 Y 对 X̂ 回归 → 系数即因果效应估计

与两样本 MR 的区别：样本同源、可调整个体协变量、能检验非线性，但对弱工具更敏感。

## 2. 数据与设计

- **基因型**：01.GWAS 项目 `mouse_hs1940.geno.txt.gz`（12226 SNP × 1940 只小鼠，真实数据）
- **表型模拟**（真实因果效应 = 0.5）：
  - X = Σ(β_g·G) + 0.8·U + e₁（暴露由 20 个工具 SNP + 未观测混杂 U 决定）
  - Y = 0.5·X + 0.8·U + e₂（结局由暴露 + 同一混杂 U 决定）
- SNP QC：MAF > 0.05（保留 10996 个），缺失基因型按 SNP 均值填补

## 3. 结果

| 方法 | 效应估计 | SE | 偏差（vs 真实 0.5） |
|---|---|---|---|
| 朴素 OLS（有混杂） | 0.856 | 0.020 | +0.356（严重有偏） |
| **2SLS（单样本 MR）** | **0.583** | 0.066 | +0.083 |
| IVW 汇总（单样本） | 0.590 | 0.067 | +0.090 |

- 第一阶段 F 统计量 = **19.6**（>10，无弱工具变量问题）
- OLS 因未校正混杂 U 而高估（0.856 vs 0.5）；2SLS 校正后接近真实值
- 单 SNP Wald ratio 估计的 IVW 汇总与 2SLS 一致（0.59 vs 0.58）

## 4. 图（04.figures/）

- `one_sample_2sls.png`：第二阶段散点与回归线（效应≈0.58）
- `one_sample_ratio.png`：单 SNP 比率估计 + IVW 竖线 + 真实值虚线

## 5. 结论与教学要点

1. **混杂是观察性研究的核心威胁**：OLS 高估 70%+，2SLS 校正后偏差 <17%
2. **F 统计量是关键诊断**：F<10 提示弱工具，2SLS 会偏向 OLS
3. 单样本 MR 与两样本 MR 结果应相互印证（本实例 2SLS≈IVW）
