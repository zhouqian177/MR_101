# 径向 MR 报告（08_radial_mr）

> 对应模块：扩展 4 —— 径向孟德尔随机化（Radial MR, Bowden et al. 2018）。
> 脚本：`scripts/13_radial_mr.R`；产物：`02.analysis/radial/`

## 1. 方法学

径向 MR 将每个工具 SNP 的贡献绘制在**径向图**上，SNP 到回归线的距离
即其 Q 统计量贡献。超过卡方阈值（df=1, P<0.05）的 SNP 判定为**离群 SNP**
（潜在水平多效性），剔除后重新估计，结果更稳健。

- Radial IVW：径向尺度逆方差加权（含 Mod.2nd / Iterative / Exact FE / Exact RE 四种估计）
- Radial Egger：同时估计截距（定向多效性）与斜率（因果效应）

## 2. 数据

真实两样本数据：端粒长度 → 冠心病（17 个工具变量，与主分析一致）。

## 3. 结果

### 3.1 Radial IVW

| 指标 | 全部 SNP | 剔除离群后 |
|---|---|---|
| 效应（Mod.2nd） | -0.243 (P=0.048) | **-0.366 (P=6.28e-05)** |
| Q 统计量 | 20.63 (df=16, P=0.19) | 9.21 (df=15, P=0.87) |
| 离群 SNP | **rs2736428** | 无 |

剔除离群 SNP rs2736428 后：效应更强、P 值更显著、异质性消失（Q P 0.19→0.87）。

### 3.2 Radial Egger

- 截距（多效性）= 0.023，SE=0.468，**P=0.962** → 无定向多效性
- 效应（斜率）= -0.251，P=0.248

### 3.3 与 MR-PRESSO 对比

| 方法 | 离群检测结果 |
|---|---|
| MR-PRESSO（03 主流程） | 全局 P=0.143，无离群 SNP |
| Radial MR（本模块） | 检出 rs2736428 为离群 |

注：Radial MR 基于精确 Q 统计量，灵敏度高于 PRESSO 的置换检验；
两方法互补，建议同时报告。

## 4. 结论

1. 径向 MR 检出 1 个潜在多效性 SNP（rs2736428），剔除后效应更显著
2. Egger 截距不显著，整体无定向多效性
3. 端粒长度→CHD 的负向因果关联在径向框架下得到进一步支持
4. 径向图（HTML）因环境 htmlwidgets 限制未成功保存，不影响数值结果
