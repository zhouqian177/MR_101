# MR 功效计算报告（25_mr_power）

> 对应模块：补充 2 —— MR 统计功效计算（Power Calculation）。
> 脚本：`scripts/40_mr_power.R`；产物：`02.analysis/power/`、`04.figures/power_curve_*.png`

## 1. 方法学

MR 统计功效（power）取决于四个核心参数：

| 参数 | 符号 | 影响 |
|---|---|---|
| 工具变量数 | K | 越多功效越高 |
| 工具强度 | R² / F | 越强功效越高 |
| 样本量 | N | 越大功效越高 |
| 真实效应 | beta | 越大功效越高 |

公式：非中心参数 λ = N·K·R²·beta² / (K·R²·beta² + N)，功效 = 1 - pchisq(χ²_crit, 1, λ)

## 2. 功效曲线

- `power_curve_N.png`：固定 K=30, R²=0.03，不同样本量下功效随效应大小变化
- `power_curve_K.png`：固定 beta=0.1, N=100000，不同 R² 下功效随工具变量数变化

## 3. 实际数据示例：LDL-C → CHD

| 参数 | 值 |
|---|---|
| K（工具变量数） | 28 |
| N（有效样本量） | 40,743 |
| R²（暴露解释方差） | 0.108 |
| beta（真实效应） | 0.403 |
| **统计功效** | **10.8%** |

LDL-C→CHD 的实际功效仅 10.8%，远低于 80% 标准。这解释为何 IVW 的 P 值仅 0.067（边缘显著）。需要约 30 万样本才能在 80% 功效下检测到当前效应。

## 4. 结论与教学要点

1. 阳性结果应检查功效：显著结果在低功效下可能是"赢家诅咒"或效应被高估
2. 阴性结果应检查功效：不显著可能是功效不足，而非真无效应
3. 功效计算也是研究设计阶段的关键工具（规划样本量/工具变量数）
