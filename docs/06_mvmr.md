# 多变量 MR 报告（06_mvmr）

> 对应模块：扩展 2 —— 多变量孟德尔随机化（Multivariable MR, MVMR）。
> 脚本：`scripts/11_mvmr.R`；产物：`02.analysis/mvmr/`

## 1. 方法学

MVMR 同时纳入**多个暴露**的工具变量，估计**校正其他暴露后**的因果效应。
解决暴露间存在相关性（如 LDL/HDL 均与 CHD 相关）时单变量 MR 的混淆问题。

- MV-IVW：多变量广义逆方差加权（主结果）
- MV-Egger：校正定向多效性
- MV-Median：对离群稳健

## 2. 模拟设计

- 个体数 n = 30000；暴露 X1、X2 各有 15 个独立工具 SNP
- 共享混杂 U 使 X1、X2 相关（rho≈0.3）
- 真实因果效应：**X1→Y = 0.4，X2→Y = -0.3**
- 由个体数据回归生成每个 SNP 对 X1/X2/Y 的汇总统计量（beta/se）

## 3. 结果

| 方法 | X1 估计 | X2 估计 |
|---|---|---|
| 单变量 IVW（未校正 X2） | 0.358（有偏） | — |
| **MV-IVW** | **0.371** | **-0.272** |
| MV-Egger | 0.308 | -0.259 |
| MV-Median | 0.389 | -0.244 |

- 真实值：X1 = 0.4、X2 = -0.3
- MV-IVW 两个暴露的估计均接近真实值，X1 的 SE 也更小（0.034）
- 单变量 IVW 因忽略 X2 而产生偏倚（0.358 vs 0.4，且方向性偏差不可预测）

## 4. 结论与教学要点

1. 暴露间相关时，**单变量 MR 结果不可信**，应使用 MVMR 校正
2. MV-Egger/Median 与 MV-IVW 方向一致，结论稳健
3. 每个暴露都需要足够的强工具（本例各 15 个）；工具不足时 MVMR 不可用
4. 真实应用中用 `TwoSampleMR::mv_extract_exposures()` + `mv_harmonise_data()` 提取多暴露工具

## 5. 可复现

```bash
Rscript scripts/11_mvmr.R
```
