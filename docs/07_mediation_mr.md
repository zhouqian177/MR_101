# 两步中介 MR 报告（07_mediation_mr）

> 对应模块：扩展 3 —— 两步孟德尔随机化中介分析（Two-step Mediation MR）。
> 脚本：`scripts/12_mediation_mr.R`；产物：`02.analysis/mediation/`

## 1. 方法学

分解暴露 X 对结局 Y 的总效应为：

- **间接效应** = a × b（第一步 X→中介 M 的效应 a × 第二步 M→Y 的效应 b）
- **直接效应** = 总效应 − 间接效应
- **中介比例** = 间接效应 / 总效应

两步各自做 MR（分别用 X 与 M 的工具变量），间接效应 SE 用 delta 法近似。

## 2. 模拟设计（真实参数）

```
X = Gx·bx + e1                    暴露（15 个工具 SNP）
M = 0.5·X + Gm·bm + e2            中介（a = 0.5）
Y = 0.3·X + 0.6·M + e3            结局（c' = 0.3, b = 0.6）
```

- 真实：间接效应 = 0.5×0.6 = 0.30；总效应 = 0.30+0.30 = 0.60；中介比例 = 50%
- n = 30000；每步 15 个工具 SNP

## 3. 结果

| 参数 | 估计 | 真实值 |
|---|---|---|
| a（X→M） | 0.489 | 0.5 |
| b（M→Y） | 0.634 | 0.6 |
| 总效应（X→Y） | 0.631 | 0.60 |
| **间接效应（a×b）** | **0.310** (SE=0.024) | 0.30 |
| 直接效应 | 0.321 | 0.30 |
| **中介比例** | **49.2%** | 50% |

## 4. 结论与教学要点

1. 两步 MR 成功复原中介结构：间接效应、直接效应、中介比例均接近真实值
2. 中介比例 49.2% 表明约一半的效应通过中介途径传递
3. 前提条件：中介的方向假设明确，两步都需满足 MR 三大假设
4. delta 法 SE 可用于构建间接效应的置信区间
5. 实际应用（如"BMI → 血压 → 冠心病"）数据获取方式与普通两样本 MR 相同，
   仅需额外提取中介的 GWAS 汇总数据

## 5. 可复现

```bash
Rscript scripts/12_mediation_mr.R
```
