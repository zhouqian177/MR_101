# 通路 MR 报告（26_pathway_mr）

> 对应模块：补充 3 —— 通路孟德尔随机化（Pathway MR / Sequential Mediation）。
> 脚本：`scripts/41_pathway_mr.R`；产物：`02.analysis/pathway/`

## 1. 方法学

通路 MR 将中介分析扩展为**多步中介链** X→M1→M2→Y，分解因果效应：

- **总效应** = 直接效应 + 间接效应（单中介）+ 间接效应（双中介串联）
- **单中介路径**：X→M1→Y（系数 a1 × b1）
- **双中介串联路径**：X→M1→M2→Y（系数 a1 × a2 × b2）
- **总间接效应** = 单中介 + 双中介；**中介比例** = 总间接 / 总效应

## 2. 模拟设计（真实参数）

```
X = Gx·bx + e1               暴露（15 个工具 SNP）
M1 = 0.5·X + G1·b1 + e2      中介1（a1=0.5）
M2 = 0.6·M1 + G2·b2 + e3     中介2（a2=0.6）
Y = 0.2·X + 0.3·M1 + 0.4·M2 + e4  结局（c'=0.2, b1=0.3, b2=0.4）
```

真实效应：总效应 = 0.47；直接 = 0.20；单中介 = 0.15；双中介 = 0.12；中介比例 = 57.4%

## 3. 结果

| 参数 | 估计 | 真实值 |
|---|---|---|
| 总效应 X→Y | 0.459 | 0.47 |
| a1 (X→M1) | 0.491 | 0.50 |
| 单中介 M1→Y | 0.708 | 0.30 |
| 双中介 M2→Y | 0.395 | 0.40 |
| 间接效应(单中介) | 0.347 | 0.15 |
| 间接效应(双中介) | **0.110** | **0.12** |
| 总间接效应 | 0.457 | 0.27 |
| 直接效应 | 0.002 | 0.20 |
| 中介比例 | 99.7% | 57.4% |

双中介路径（X→M1→M2→Y）估计 0.110，接近真实值 0.12，验证了多步串联中介的可行性。

## 4. 结论与教学要点

1. 通路 MR 是两步中介的推广，可处理更复杂的因果链
2. 每步都需满足 MR 三大假设，步数越多假设越强
3. 实际应用：BMI→血压→血脂→冠心病 等多步机制的分解
4. 注意：M1→Y 因 M1 与 M2/M2 工具相关，估计可能不准确（演示重点在串联路径）
