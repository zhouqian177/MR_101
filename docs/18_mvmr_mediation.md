# 多变量中介 MR 报告（18_mvmr_mediation）

> 对应模块：进阶 4 —— 多变量中介孟德尔随机化（MVMR-based Mediation）。
> 脚本：`scripts/33_mvmr_mediation.R`；产物：`02.analysis/mvmr_mediation/`

## 1. 方法学

将 MVMR 与中介分析结合，在**校正中介 M 的混杂**后分解因果效应：

- **总效应**：MR(X → Y)，用 X 的工具变量
- **直接效应**：MVMR 同时纳入 X 与 M 的工具变量 → X 的校正系数 c'
- **间接效应** = 总效应 − 直接效应（差值法）；或 a×b 乘积法
  （a = X→M 用 X 工具，b = MVMR 校正后 M→Y 效应）
- **中介比例** = 间接效应 / 总效应

相比两步中介 MR（扩展 3），MVMR 版在校正暴露与中介的相关性后
估计直接效应，避免中介工具变量与暴露混杂。

## 2. 模拟设计（真实参数）

```
X = Gx·bx + 0.5U + e1      暴露（15 个工具 SNP）
M = 0.6X + Gm·bm + 0.5U + e2   中介（a=0.6）
Y = 0.3X + 0.5M + 0.5U + e3   结局（直接 c'=0.3, b=0.5）
```

真实：总效应 = 0.3 + 0.6×0.5 = **0.60**；直接 = **0.30**；
间接 = **0.30**；中介比例 = **50%**。n = 30000。

## 3. 结果

| 参数 | 估计 | 真实值 |
|---|---|---|
| 总效应（MR X→Y） | 0.631 | 0.60 |
| 直接效应（MVMR 校正后 X） | **0.293** | 0.30 |
| MVMR 校正后 M 效应 b' | 0.521 | 0.50 |
| 间接效应（差值法） | 0.338 | 0.30 |
| 间接效应（乘积法 a×b） | 0.346 | 0.30 |
| **中介比例** | **53.6%** | 50% |

各参数均接近真实值，差值法与乘积法交叉验证一致。

## 4. 结论与教学要点

1. MVMR 直接效应 = 校正中介后的暴露效应，可识别"通过中介"与"直接"两条通路
2. 中介比例 53.6% 表明约一半的 X→Y 效应经 M 介导（真实 50%）
3. 适用场景：BMI→血压→冠心病、吸烟→炎症→肺癌等多步骤机制研究
4. 前提：X 与 M 都需足够强且相互独立的工具变量；中介方向需有生物学依据
