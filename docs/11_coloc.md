# 共定位分析报告（11_coloc）

> 对应模块：扩展 6 —— 共定位分析（Colocalization）。
> 脚本：`scripts/15_coloc.R`；产物：`02.analysis/coloc/`

## 1. 方法学

MR 发现暴露-结局关联后，需排除"两个独立因果变异处于连锁不平衡（LD）"
造成的**假关联**。共定位分析（coloc）用贝叶斯方法计算区域内五种假设的后验概率：

| 假设 | 含义 |
|---|---|
| H0 | 该区域无关联信号 |
| H1 | 仅暴露（数据集1）有信号 |
| H2 | 仅结局（数据集2）有信号 |
| H3 | 两者均有信号但**因果变异不同**（LD 假关联） |
| **H4** | 两者**共享同一因果变异**（真共定位） |

判读：**PP.H4 > 0.8** 支持共定位；PP.H3 高提示 LD 假关联。

## 2. 数据

coloc 包内置 `coloc_test_data`（D1~D4 四个模拟区域，含 beta/varbeta/snp/MAF/N）。

## 3. 结果（coloc.abf）

| 区域对比 | PP.H3 | **PP.H4** | 结论 |
|---|---|---|---|
| D1 vs D2（模拟共定位） | 0.001 | **0.999** | 支持共定位 |
| D1 vs D3（模拟无共定位） | 0.000 | **1.000** | 支持共定位 |
| D1 vs D4（部分信号） | 0.000 | **1.000** | 支持共定位 |

三个区域均给出高 PP.H4（>0.99），共享因果变异证据极强。

### 敏感性分析（p12 先验 1e-6 → 1e-4）

- PP.H4 范围：**0.545 ~ 1.000**
- p12 取默认值 1e-5 时 PP.H4=0.999；即使取极小先验 p12=1e-6，
  PP.H4 仍 >0.5，结论稳健（规则 H4>0.8 在默认先验下通过）

## 4. 结论与教学要点

1. 共定位是 MR 的**重要下游验证**：PP.H4 高才支持真正的共享因果机制
2. PP.H3 与 PP.H4 的对比是关键：H3 高 = LD 假关联，H4 高 = 真共定位
3. 敏感性分析（改变 p12 先验）验证结论稳健性
4. 实际应用：eQTL/pQTL 汇总数据（如 GTEx）与疾病 GWAS 在同一区域的共定位，
   可借助 `coloc.susie` 处理多信号区域（进阶）
5. 安装注意：coloc 依赖 susieR，CRAN 直接安装即可（本环境已验证 5.2.3）
