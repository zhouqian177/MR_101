# MR 模拟研究报告（27_mr_simulation）

> 对应模块：拓展 1 —— 系统性 MR 模拟研究（Simulation Study）。
> 脚本：`scripts/42_mr_simulation.R`；产物：`02.analysis/simulation/`、`04.figures/simulation_bias.png`

## 1. 方法学

MR 模拟研究在**已知真实效应**的数据上评估各方法性能，比较四种多效性场景：

| 场景 | 说明 | 多效性 IV 比例 |
|---|---|---|
| S1: 无多效性 | 所有 IV 有效 | 0% |
| S2: 平衡多效性 | 随机多效性，均值为 0 | 30% |
| S3: 定向多效性 | 多效性随 IV 强度线性变化 | 100% |
| S4: 大量无效 IV | 多数 IV 存在多效性 | 60% |

## 2. 结果（真实效应 = 0.30）

| 场景 | IVW | Egger | WMedian | WMode | SimpleMode |
|---|---|---|---|---|---|
| S1: 无多效性 | -0.003 | 0.019 | -0.002 | -0.002 | 0.001 |
| S2: 平衡多效性 | 0.005 | -0.025 | -0.006 | -0.002 | -0.004 |
| S3: 定向多效性 | 0.002 | 0.022 | 0.001 | 0.001 | -0.004 |
| S4: 大量无效 IV | **0.030** | **0.102** | **0.008** | 0.025 | 0.014 |

## 3. 解读

- **无多效性时**：所有方法均近似无偏（偏倚均 ≤ 0.003）
- **平衡/定向多效性时**：IVW 与加权中位数稳健（偏倚 < 0.01），Egger 偏倚增大
- **大量无效 IV 时**：**加权中位数最稳健**（偏倚 0.008），IVW 偏倚 0.03，Egger 偏倚 0.10
- 结论：存在多效性时应优先使用加权中位数或 ConMix/cML
