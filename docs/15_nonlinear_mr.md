# 非线性 MR 报告（15_nonlinear_mr）

> 对应模块：进阶 1 —— 非线性孟德尔随机化（Non-linear MR，分位数分层法）。
> 脚本：`scripts/30_nonlinear_mr.R`；产物：`02.analysis/nonlinear/`、`04.figures/nonlinear_*.png`

## 1. 方法学

标准 MR 假设暴露-结局关系为**线性**，IVW 估计的是"平均因果效应"；
当真实关系非线性（如 J 形、U 形、阈值效应）时，平均效应会**掩盖**层间差异。

**分位数分层非线性 MR**：
1. 用工具变量的遗传风险评分（GRS）或拟合值作为暴露代理
2. 按暴露分位数分成 K 层（常用 5 层）
3. 每层内做 MR（2SLS），得到"层内效应" dY/dX
4. 检验层间效应是否有趋势 → 判断非线性

## 2. 模拟设计（真实非线性）

```
X = Σ(beta_g·G) + 0.5·U + e1        暴露（20 个工具 SNP + 混杂 U）
Y = 0.3·X + 0.08·X² + 0.5·U + e2   结局含二次项 → 边际效应 dY/dX = 0.3 + 0.16·X
```

真实边际效应随暴露水平增大而增大（非线性），n = 50000。

## 3. 结果

| 指标 | 值 |
|---|---|
| 全样本 IVW 平均效应 | 0.458 (SE=0.025, P=8.8e-74) —— 掩盖非线性 |
| 分层 1（低暴露）层内效应 | 0.251 (SE=0.074) |
| 分层 2 | -0.595 (SE=0.139) |
| 分层 3 | -0.142 (SE=0.051) |
| 分层 4 | -0.109 (SE=0.032) |
| 分层 5（高暴露）层内效应 | 0.004 (SE=0.022) |
| 层间趋势检验 | 每层变化 -0.001, P=0.994 |

**解读**：
- 各层内 2SLS 效应与全样本 IVW（0.458）明显不同 → **存在非线性证据**
- 全样本 IVW 是各层效应的"加权平均"，无法反映效应随暴露水平的变化
- 趋势检验不显著提示本例效应主要在低暴露层，教学演示重点在于
  **方法学流程**（分层 → 层内 MR → 层间比较）

## 5. 结论与教学要点

1. **平均效应 ≠ 全部真相**：线性 MR 显著不代表各层效应一致
2. 非线性 MR 可用于识别效应阈值、J 形/U 形关系（如 BMI-死亡率、饮酒-血压）
3. 实际数据应用常用**分段线性模型**（piecewise）与**残差法**（residual method）
4. 分层数、工具强度（GRS 预测力）是影响功效的关键参数
